# 🚀 Portfolio Website

A modern, responsive personal portfolio website built using **React** and **TailwindCSS** to showcase my projects, skills, and contact information.

---

## 🔥 Features

- Responsive navbar with mobile menu  
- Hero section with typing animation  
- About me section  
- Reusable project cards  
- Contact form with real email sending (EmailJS)  
- Professional footer  
- Fully responsive design  
- Clean and modern UI  

---

## 🛠️ Tech Stack

- React  
- Tailwind CSS  
- React Icons  
- React Type Animation  
- EmailJS  

---


## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

### 2️⃣ Install dependencies

### 3️⃣ Start the development server

npm run dev

App will run on:
http://localhost:5173
